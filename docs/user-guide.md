# EV macOS 使用指南

## 当前版本

EV 目前是依赖仓库 `.venv` 的 Apple Silicon macOS 14 开发版。它可以持续监听、实时
转写、生成高质量终稿、自动学习用户声纹，并把所有 VAD 人声段保存到本机。当前不会调用
LLM，也不会生成回复或语音。

## 首次启动

1. 在仓库根目录安装开发环境：

   ```bash
   uv sync
   uv pip install funasr torch torchaudio
   ```

2. 构建并打开 App：

   ```bash
   xcodebuild -project apps/macos/EV.xcodeproj -scheme EV \
     -configuration Debug -derivedDataPath /tmp/ev-derived \
     CODE_SIGNING_ALLOWED=NO build
   open /tmp/ev-derived/Build/Products/Debug/EV.app
   ```

3. 打开“模型”。若四个模型都显示已就绪，直接继续；否则点击下载。下载会校验固定
   SHA256，完整验证后才替换目标目录。
4. 打开“实时”，选择输入设备并点击“开始监听”（或按 **Ctrl+T**）。首次使用时允许 EV 访问麦克风。

## 声纹学习

声纹在正常使用过程中自动学习，不需要显式录入流程：

- **0 个核心样本（未建立）**：所有语音直接接收，用于冷启动收集样本
- **1-2 个核心样本（学习中）**：所有语音接收，继续自动学习
- **≥3 个核心样本（已就绪）**：声纹门控激活，只有本人语音触发指令

也可以在“声纹”页面手动添加样本作为种子。样本库分层管理：
- **核心样本（最多 20 条）**：用于 K-means 多质心建模，高分样本优先保留
- **缓存样本（最多 50 条）**：仅记录备查，不参与建模，FIFO 淘汰

样本支持手动删除，也支持将缓存样本提升到核心集。

## 实时监听

- 点击按钮或按 **Ctrl+T** 切换监听/停止状态（快捷键默认开启，可在设置关闭）。
- 中央显示加载、监听、检测到语音、后台处理、完成或错误状态。
- 说话时显示累计 partial；停顿后显示 Paraformer Large 终稿，并保留最近结果。
- 每个检测到的人声段都会保存到本地历史，不会因为识别为“他人”被丢弃。
- 说 **“小E”**（支持“嗨小易”“喂小艺”等同音变体）开头，且声纹验证为本人时，去除前缀后
  的文本才进入待处理输入。
- 当前没有多轮激活：下一段指令需要再次说“小E”。

停止监听时，如果正在说话，EV 会 flush 当前段并等待后台完成。关闭主窗口不会退出；
可从菜单栏暂停或恢复。退出 EV 时会先通知引擎停止并排空已结束段。

## 历史与手动输入

“历史”可在“语音记录”和“待处理输入”间切换。语音记录支持日期、说话人（全部/我/他人）
和“仅指令输入”筛选，支持一键回放、在 Finder 显示和删除（删除无确认对话框，操作即时生效）。
删除语音段时会同时删除 WAV 文件与关联的声纹样本。

“实时”页底部的“手动输入”会直接写入待处理队列，来源标记为 `manual`。当前队列没有
LLM 消费者，因此状态保持 `pending`。

## 设置

- **声纹判定阈值**：单一滑块控制（范围 0.30–0.80，默认 0.50）。高于此分数判定为本人，
  低于则判定为他人。实时生效，修改立即影响后续识别。
- **Ctrl+T 快捷键**：可开启/关闭全局监听切换快捷键。
- **数据目录**：可在 Finder 中打开数据目录或查看引擎日志。

## 本地数据

默认目录为 `~/Library/Application Support/EV/`：

```text
models/   四个本地模型
archive/  按日期保存的 WAV
ev.db     语音元数据、声纹样本和 query 队列
logs/     Python engine 日志
```

## 常见问题

**没有输入设备**

在“设置”确认麦克风权限为“已允许”，再检查 macOS“系统设置 > 声音 > 输入”。重新插拔
外接麦克风后重启 EV。

**点击监听后没有转写**

先看输入电平是否变化。电平不动通常是设备或权限问题；电平变化但一直没有语音段时，
检查“设置 > 最近引擎日志”，确认 FSMN-VAD 和 Paraformer 已加载。正常说完整一句并停顿，
终稿会在端点后生成；首次加载模型会更慢。

**日志出现 `rtf_avg` 或彩色进度条**

当前版本已对所有 FunASR 调用设置 `disable_pbar=true`。若仍出现，通常运行的是旧 App 或
旧 Python 进程。退出 EV，重新构建，再从新的 Debug 路径启动。

**一直停在加载**

打开“模型”确认四项均已就绪，再查看日志中的具体模型路径。开发版必须从包含 `.venv`
的仓库构建；移动 App 后可设置 `EV_REPO_ROOT=/absolute/path/to/EV`。

**声纹识别不准确（唱歌/音色变化/远场被拒）**

1. 确保正常使用中积累了 5 个以上核心样本，覆盖不同音色状态
2. 可在设置中适当调低阈值（如调到 0.45）降低拒绝率
3. 已支持响度归一化减少距离/音量影响，多质心模板覆盖不同音色状态
4. 未来版本将支持定制热词和更精细的声纹自适应
