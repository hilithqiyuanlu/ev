# EV 研究基座:挑战 → 研究问题 → 发表地图

> 定位:EV 既是产品目标,也是研究平台。本文档长期维护每条工程挑战对应的研究问题、候选发表地与所需证据。
> 策略:一平台双轨 —— AI 会议发方法/基准,HCI 会议发交互研究。

## 研究基座的三条工程要求(已并入 phase1a 计划)

1. **确定性回放**:原始语音段全留 → 任意策略/模型可对历史输入重放,回答反事实("换检索策略 B,上周 30 次交互会怎样")——消融与复现的根基。
2. **配置化消融**:检索/门控 τ/打断策略一律进 ev.toml,不写死代码;一次实验 = 一份配置 + 一次回放。
3. **主观体验采样(ESM)**:每日轻量日记/评分,与客观指标(延迟、打断日志)对齐 —— HCI 证据链缺它不行。
4. **场景仿真**:以存档音频 + 合成注入构造可控实验场景(如“会议中被旁观者打断”),与回放互补。

四条对应平台能力:实验框架(消融)、可观测性(追踪)、数据管理(存档)、仿真环境(场景仿真)。

## 方法备忘

- **autoethnography / 长期部署**:n=1 自己用数月,CHI 有明确先例;我是 EV 的重度用户,这是天然资产。
- **toolkit 论文**:UIST/CHI 传统,把平台泛化、降低同行复现门槛,本身即可成文。
- **一鱼两吃**:同一平台,方法投 AI 会议,交互研究投 HCI 会议。
- **时效校准**:立项前翻近两年 CHI/UIST/CUI/ACL 的 agent 相关论文,校准定位(本文档基于既有认知,venue 口味会漂移)。
